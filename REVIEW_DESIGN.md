# Review extension

This extension follows the original analysis. The published 2025 edition has already been used for scoring some later portfolios. The extension is a retrospective robustness study, with no independent preregistration. The following choices were recorded before computing its scores.

- Retain the eight-quarter landmark, twenty-quarter horizon, eight-vintage lookback and count-incidence endpoint. Keep the original 1999Q1–2015Q4 panel. Evaluate the consecutive, disjoint 2016Q1–2019Q3 disbursement quarters supported by both programs in the 2025 release. Evaluate its fixed-landmark point forecasts from that file with date masking. Report the 504-only extension through the last fully seasoned quarter separately.
- Compare recent versus mature windows within each forecast family using both equal-vintage and loan-volume reference weights. Score every method on the same quarters within a comparison. The scored portfolio unit remains one vintage. Tabulate changes in MAE, including signs on individual portfolios. In the original panel remove all quarters for which any potentially used reference or target event quarter intersects 2007Q4–2009Q2. The complete support interval is [v−19,v+19] at this landmark and width.
- For benchmarks of stress coverage, describe every overlap of the 12-quarter forecast tail with the 2001, 2007–09 and 2020 US recessions, using quarters containing the monthly peak and trough. Disclose absent calibration histories. Count distinct stresses separately from overlapping vintages. Use the original replay for vintages through 2015Q4 and the 2025 replay for subsequent complete vintages. Calibration uses the same twenty matured errors as the original, following the same edition by vintage. This retrospective composite deliberately preserves the previously published historical errors.
- Use the pinned September 2022 7(a) and 504 release files as an additional genuine issue date. Score all available origins against the September 2025 archive at ages 8–19, within complete common entry support, and separately display only age eight. Identify the reason for omitted age-eight observations. Recompute both forecast families from final-edition inputs after masking future event dates, with the same target outcome, age and donor coverage. Report the actual and reconstructed differences in MAE; enumerate rank reversals at the program–issue level. Each release is a measurement occasion. Adjacent releases share vintages and economic conditions.
- Treat the historical term subgroups as final-file descriptions. A final-file contract term lacks documented issue-time provenance in the rolling replay. It cannot validate prospective segmentation.

As an explanatory diagnostic, retain the published cap on incidence and evaluate a two-factor substitution within the multiplicative forecast. At each age separately switch the conditional factor's increment and its cumulative base between the mature and recent pools. Average each component's change in absolute loss over the two substitution orders. These hybrid forecasts are accounting devices. This decomposition attributes the measured loss contrast to the two data substitutions and does not identify causes of borrower distress.

## Archive inclusion and interpretation

The September 2022 7(a) file contains 545,751 approval records (FY2010–19), and the 504 file contains 94,673 (FY2010 onward). All rows carry the September 30, 2022 as-of date. We retained all rows in the date projection before applying the original funded-cohort eligibility rule. For 7(a), complete disbursement coverage ends in 2019Q3 in both the September 2022 and final slices. The 504 sources also support later origins.

Two earlier candidate sources were screened out. The [September 2019 teaching file](https://github.com/nehasawant327/loan_program_analysis/blob/4191e64fa6bfa91f88b89cf7931cb3fd3a0f4348/7a_new_1.csv) has 222,931 rows and only paid-in-full, charge-off and committed statuses, so it cannot supply the funded denominator. The [older 504 workbook](https://github.com/Lingyi-lk/MSE246-2018-Project/blob/ec9721e79e23a0fae57a0e90d2409551f29a31a5/data_processed_final/SBA_Loan_data_.xlsx) omits the first-disbursement field. Its approval-date cohorts would target a different population. Source availability is selective. Counts of sign reversals across the retained files are descriptions of those files.
